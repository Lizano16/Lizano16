## 🚀 Proyecto principal

### 🛡️ [AegisDesk AI](https://github.com/Lizano16/aegisdesk-ai)

Plataforma full stack de soporte técnico con gestión de tickets, usuarios, roles, SLA, auditoría, base de conocimiento e inteligencia artificial local mediante Ollama.

<div align="center">

[![Ver AegisDesk AI](https://img.shields.io/badge/Ver_repositorio-AegisDesk_AI-6C47FF?style=for-the-badge&logo=github)](https://github.com/Lizano16/aegisdesk-ai)

<br><br>

  width="900"
/>

</div>

### Funciones principales

- Gestión completa de tickets
- Categorías, estados y prioridades
- Control de SLA
- Roles de solicitante, técnico, supervisor y administrador
- Autenticación multifactor
- Auditoría y trazabilidad
- Base de conocimiento
- Sugerencias de resolución mediante IA local
- Arquitectura basada en Docker Compose

### Tecnologías utilizadas

`Django` · `Django REST Framework` · `React` · `TypeScript` · `PostgreSQL` · `pgvector` · `Redis` · `Celery` · `Docker` · `Nginx` · `Ollama`
